# Xander Theron — CV

My online curriculum vitae: a small, dependency-free static site (HTML + CSS + a
little vanilla JS). No build step — open `index.html` or deploy to GitHub Pages.

## Project structure

```
certs/            Drop scans of new certificates in here (that's the whole workflow)
certs.html        Certifications page — REGENERATED by tools/build-certs.mjs
index.html        Home: narrative intro, what I do, currently, projects, journey, CV
about.html        A little more about me
blog.html         Notes & Experiments + link to my WordPress blog
assets/           Site images (portrait, cover, favicon)
tools/build-certs.mjs   Regenerates certs.html from the certs/ folder
styles.css        Design tokens + all styling (light & dark themes)
main.js           Theme toggle, certificate lightbox + live blog-feed fetch
```

## Adding a certificate

1. Put the image in `certs/`.
2. Name the file so it reads like the title, e.g. `01 First Aid Level 3.jpg`.
   A leading number like `01-`, `02-` controls the order. Spaces/dashes in titles
   are fine; the caption is derived from the file name.
3. Rebuild the page and commit:

```bash
npm run certs     # regenerates certs.html
git add certs certs.html
git commit -m "Add certificate: First Aid Level 3"
git push
```

That's it. No edits to HTML needed — new certificates appear on the
Certifications page automatically, clickable for a full-size lightbox view.

## Changing the portrait

Save a roughly 3:4 crop as `assets/portrait.jpg` and update the `<img>` src in
`index.html`.

## Adding field photos

The homepage and About page each have a dashed placeholder plate labelled
"Field photo — yours goes here". Replace the `<div class="photo-plate">` with an
`<img>` (or add `<img>` inside a `<figure class="figure-photo">`) to drop real
photos into the story. Good candidates: you at a campsite, working with young
people, or outdoors.

## Editing the CV content

The narrative homepage lives in `index.html`. Skills are grouped in the `Skills`
section; the big picture is the `My Journey` strip, and roles are in the
`Career Experience` timeline (most recent first). The blog feed on the homepage
and Blog page is fetched live from the WordPress.com public API — it updates
automatically when you post.

## Layout / design

- "Field notebook" identity: Instrument serif/sans + IBM Plex Mono labels,
  mono uppercase kickers (`FIELD NOTES`, `PROJECT 01`), subtle grid texture
- Type scale: perfect fifth (1.500), display serif + text sans + mono labels
- One accent colour (forest green), used only for small details
- No cards, no shadows; hierarchy from rules and spacing
- Colour contrast verified to WCAG AA in both light and dark themes
- `Print / PDF` on the page produces a clean, print-styled CV via `window.print()`
  (narrative/visual sections are hidden; the CV is the hero + skills + timeline)

## Deploy to GitHub Pages

1. Make the repository **public** (Settings → General → Change visibility).
2. Settings → Pages → Source: **Deploy from a branch**, branch `main`, root `/`.
3. The site is then live at `https://<username>.github.io/XanderCV/` after a
   minute or two.
